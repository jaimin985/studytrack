Quick Help

  1. Go to Google Account Security
  2. Enable 2-Step Verification (if not already on)
  3. Go to App Passwords
  4. Create a new App Password for "Mail" → "Other" → name it "StudyTrack"
  5. Copy the 16-character password into SMTP_PASSWORD in .env
  6. Set SMTP_USERNAME to your Gmail address
  7. Restart: docker compose down && docker compose up -d
